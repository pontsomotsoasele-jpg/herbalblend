# Herbal Blend

This project is a professional two-page React application for a herbal wellness brand. It includes a home page and a contact page, both designed to be responsive, modern, and aligned with the assignment requirements.

## Project Overview

- Home page with hero section, navigation, about section, services/features, and footer
- Contact page with a complete validation-ready form
- JavaScript input validation with inline error messages
- Form submission that shows a confirmation message without reloading the page
- Reusable React components and functional patterns using JSX, props, state, and effects

## Tech Stack

- React JS
- JavaScript
- HTML
- CSS
- React Router

## Run Locally

```bash
npm install
npm start
```

Then open http://localhost:3000

## Test

```bash
npm test -- --watch=false
```
